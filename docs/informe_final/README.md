# Informe para el chat de documentos (B17, borrador)

Material para el documento de grado del sistema multiagente de IA, con la estructura de la sección
8.18 de la especificación técnica, con las cifras finales: la corrida 3 (B16), la calibración con
personas, la usabilidad, la disponibilidad y las capturas definitivas. Lo único marcado **PENDIENTE
(verificar)** son los datos bibliográficos de `04_fuentes_nuevas.md`, que confirma el chat de
documentos.

Reglas de redacción: cada cifra lleva su archivo de origen (de `reports/` o de `docs/resumenes/`);
pasado e impersonal; sin fechas exactas del trabajo; el proyecto, siempre «sistema multiagente de
IA»; los RF y RNF con su nombre corto.
